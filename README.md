# Echo Purgatory Game Project

This is the project repository for our 2D story-driven action platformer game. It follows the journey of our main protagonist trying to escape a dimension of purgatory while resisting a dark curse in the form of a parasitic plant taking over their body.

## Project Structure

```
Project  
├── addons  
├── assets  
│   ├── gfx  
│   └── sfx  
├── obj  
│   └── levels  
└── src  
```

### Assets

- `assets/gfx` all graphic files live here (`.png`, `.aseprite`, `.svg`, etc.), organized into subdirectories as necessary
- `assets/sfx` all audio files live here, organized into subdirectories as necessary

### Data Files

- `obj/levels` scenes that act as level environments for the player to go through
- `obj` all other godot resource files live in appropriate subdirectories of this folder (`.tscn`, `.tres`, etc)

### Source Code

- `src` all source code files should live in appropriate subfolders of this directory. This includes, godot scripts and shader code
